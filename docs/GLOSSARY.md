# Glossary

| Term | Meaning |
|------|---------|
| **Brain** | Central service: mind, soul storage, sync, tool orchestration |
| **Soul** | Persona, memory, preferences — who it is to you |
| **Mind** | LLM agent loop that plans and calls tools |
| **Hands** | Anything that changes the world (tools, bridges) |
| **Presence** | Surfaces you talk through (phone, PC, rooms) |
| **House body** | Home hub + room endpoints + IoT bridges |
| **Tool** | Named, schema’d capability the Mind can invoke |
| **Plugin** | Packaged tool(s) added without rewriting the brain |
| **Sync** | Keeping identity, memory, sessions consistent across bodies |
| **Devloop** | Repo script that runs the internal AI app-dev feedback loop |
| **Board** | Living markdown status: NOW / NEXT / DONE / issues |
| **Issue** | One work package with acceptance criteria |
| **Phase** | Delivery gate (D0, D1, 0…6) |
| **ADR** | Architecture Decision Record in DECISIONS.md |
